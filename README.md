# FORGED - Elite Athletic & Performance Club Website

FORGED is a modern full-stack web application for a premier high-end athletic facility and performance gym. Built with Next.js 16, React 19, TypeScript, Tailwind CSS, and Framer Motion.

---

## Features

- **Modern Luxury Design:** Dark high-contrast aesthetic with smooth micro-animations.
- **Interactive Navigation:** Smooth sticky navigation with active link highlighting.
- **Hero & Motion Highlights:** High-impact animated headers and interactive call-to-action sections.
- **Programs & Pricing:** Structured membership breakdown with feature cards.
- **Athlete Showcase & Testimonials:** Real member results, testimonials, and gallery grid.
- **Interactive FAQ Accordion:** Clean animated query toggling.
- **Blog & Articles Section:** Insights on athletic performance and nutritional science.
- **Fully Responsive:** Optimized across mobile, tablet, and widescreen desktop displays.

---

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **UI & Styling:** [Tailwind CSS v4](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** TypeScript

---

## Getting Started

1. Navigate to the `client` directory:
   ```bash
   cd client
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
